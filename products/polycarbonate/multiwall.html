Read the internal structure

Compare section drawings before comparing product names. Wall arrangement, chamber geometry and thickness are separate specification choices, and two sheets of similar appearance may require different supporting details. Ask for the exact section reference and the evidence supporting any proposed thermal or structural values. Consider the visual effect of the ribs using a sample viewed in the intended installation direction.

Plan the chamber direction

Mark the chamber direction on each elevation or roof layout and check it against the intended drainage route and the manufacturer’s installation instructions. Coordinate cuts, supports and openings before finalising panel lengths. Ask how interrupted chambers around penetrations will be treated. The designer should review the complete arrangement instead of assuming that rotating a rectangular panel is an interchangeable layout choice.

Specify the ends as part of the system

Request a detail for each chamber end, including the specified sealing or ventilation tape, protective profile and drainage provision where applicable. Confirm which materials are compatible and which end treatment belongs at each position. Include these items in the quantity schedule and ask for storage and installation instructions that keep the chambers clean. Inspect exposed ends and packaging at receipt before the panels enter the installation sequence.

Build your project specification

  1. Application and destination: roof, facade, partition or glazing; project location and required approvals.
  2. Panel schedule: section type, thickness, cut length, effective width, quantity, colour and transparency.
  3. System details: support spacing, joints, fixings, end closures, drainage and movement allowances for engineering review.
  4. Evidence and order terms: request a current drawing, sample, model-specific test documents, packing plan and written quotation.
