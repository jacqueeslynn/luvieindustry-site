Define the complete raised-joint assembly

Treat the solid panel and its raised locking connection as one coordinated system. Ask for a section through the joint showing the actual panel edge, connector and relationship to the support. Confirm which components are included in the offer and which must be supplied locally. A panel sample alone cannot establish how the assembled joint fits or how it will be installed.

Build a node-by-node component list

Identify internal joints, starting and finishing edges, corners, changes of direction and any wall or gutter interfaces on the project drawings. Request the connector, clip, fixing, gasket or closure specification applicable to each node, where used. Record component references beside the corresponding drawing details and reconcile quantities with the panel schedule. Ask explicitly whether cutting or drilling affects the proposed connection arrangement.

Review installation and project evidence

Request an installation sequence showing access for engaging the joint, fixing the assembly and allowing the specified movement. Have the project designer review support conditions and interfaces before approving fabrication. If performance documents are supplied, check that their tested assembly corresponds to the offered panel and connection components. Confirm the inspection points and replacement procedure so the installer understands how an individual panel would be accessed after completion.

Build your project specification

  1. Application and destination: roof, facade, partition or glazing; project location and required approvals.
  2. Panel schedule: section type, thickness, cut length, effective width, quantity, colour and transparency.
  3. System details: support spacing, joints, fixings, end closures, drainage and movement allowances for engineering review.
  4. Evidence and order terms: request a current drawing, sample, model-specific test documents, packing plan and written quotation.
