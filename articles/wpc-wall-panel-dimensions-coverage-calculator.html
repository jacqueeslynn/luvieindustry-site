Independent evidence

NIST’s SI area guidance identifies the square metre as the SI unit of area. The arithmetic is simple, but product ordering still depends on effective coverage, orientation, cuts, cartons and the confirmed profile. This page provides a planning method, not a substitute for the project drawing or supplier quotation.

Subtract openings carefully

A large door can reduce face area, but it may not reduce the number of full-length panels by the same proportion. The strips beside the opening, header area, pattern direction and cut reuse all affect the result.

Mark windows, doors, columns, sockets and service panels on an elevation. Count full runs first, then decide whether offcuts can be reused without creating weak joints or an unacceptable pattern break.

What changes when panels run horizontally?

The calculator above is deliberately limited to one straight wall with vertical, full-height panels. For horizontal installation, count the number of courses up the wall using the connected panel's effective coverage width. Then determine how many supplied lengths are needed across each course, accounting for joints, stagger pattern and usable offcuts. Do not reuse the vertical panel count as a horizontal order quantity.

For example, a 2.8 m high wall with an effective face width of 0.19 m needs 15 horizontal courses before any allowances. That is only the first step: if the wall is wider than the supplied length, each course may require more than one piece and an approved joining detail. Make a row-by-row cutting schedule when the design calls for aligned grooves or a repeating finish.

Record the dimensions that actually control the order

A buyer may receive an overall width, a decorative face width and a connected effective width for the same profile. These are not interchangeable. Overall width helps with packing and handling; effective width determines installed coverage. Usable length may also differ from a headline length if ends are trimmed or site cuts are required.

Ask the supplier to mark the measurement points on a profile drawing and confirm them against a connected physical sample. Record units consistently: divide millimetres by 1,000 before using them with wall dimensions in metres. Keep the approved drawing with the packing list so the warehouse does not substitute a visually similar profile with a different coverage width.

From wall elevation to carton quantity

After counting whole pieces, check whether the selected model is sold by piece, carton or bundle. If a carton contains a fixed number of panels, round the requirement up to whole cartons; do not round the measured wall area alone. Keep a separate line for trims because starters, corners and transitions are usually measured by linear length, not square metres.

Before confirming the order, compare your schedule with the supplier's current packing data, carton labels and finish codes. For a multi-room project, combine quantities only after confirming that the same model, length, finish and approved batch can serve each room. Convert the calculation into a purchase order

  • Selected model and connected profile drawing.
  • Effective coverage width, total panel width, thickness and available length.
  • Vertical or horizontal layout and start point.
  • Net wall dimensions plus openings and corner conditions.
  • Cutting, damage and future-replacement allowance agreed for the project.
  • Panels per carton, carton dimensions, gross weight and loading plan.
  • Starter, end, inside-corner and outside-corner accessories measured separately.

Three quantity mistakes importers can prevent

Using nominal width. The difference between nominal and effective width compounds across a long wall.

Ordering exact net area. Square metres do not account for last cuts, pattern direction, unusable offcuts or carton rounding.

Forgetting replacement stock. A project may need matching material later. Agree a practical reserve while the approved batch is available rather than assuming a later batch will be visually identical.

Buyer FAQ

How many WPC wall panels are needed per square metre?

Divide one square metre by the confirmed face coverage per connected panel, then adjust for the actual wall layout, cuts and carton units. There is no universal answer without the effective width and length.

Should I use nominal width or effective width?

Use effective coverage width for quantity planning. Nominal width may include joining geometry that disappears when panels connect.

How much waste allowance should I add?

It depends on layout, openings, pattern direction, installer method, damage risk and replacement needs. Agree the allowance from the elevation instead of applying one universal percentage.

Are trims included in square-metre calculations?

No. Measure starters, ends, corners and transitions by linear length and convert them to the supplier’s accessory lengths and packing units.
