UV marble sheets for Mexico: reconcile inch and millimetre dimensions before cutting

A Mexico project may involve a designer, importer and fabricator exchanging drawings from different systems. If one attachment uses inches and another uses millimetres, apparently similar numbers can describe different pieces. This is not a claim that Mexican projects use one particular drawing convention. It is a purchasing check for any order where mixed units actually appear. For UV decorative sheets, resolve the dimensional handoff before asking a supplier to prepare a cutting proposal or confirming that an offered sheet can cover the intended layout.

Short answer

Choose one controlling unit for the approved cutting information, retain the original dimension and unit beside each conversion, and separate mathematical conversion from fabrication tolerance. NIST defines one inch as exactly 25.4 millimetres. That relationship does not establish a Luvie sheet size, a cutting capability or an acceptable installation gap.

Independent reference

Identify the unit on every incoming dimension

Check the drawing title block, dimension notes and any separate spreadsheet instead of assuming that all attachments follow the same convention. Ask the originator to clarify a number with no unit. Record whether a dimension describes a finished piece, a rough opening, a full sheet or a nominal commercial description. These are not interchangeable simply because their numerical values are close. Mark the intended face and the direction of the decorative pattern separately from length and width. A mathematically correct rectangle can still be the wrong piece if its orientation is reversed. Keep uncertain entries out of the released cutting schedule.

Convert from the source, not from a rounded copy

NIST's length reference states that an inch is exactly 25.4 millimetres. As a mathematical example only, 10 inches therefore equals 254 millimetres; this example is not a product dimension. Retain the source value and calculate the conversion from it rather than repeatedly converting a rounded display value between systems. If a spreadsheet rounds numbers for readability, preserve the underlying result and ask the drawing owner how the approved dimension should be expressed. Do not let a copied screenshot become the only dimensional record. Have a second person check the unit and calculation for critical entries before the schedule leaves purchasing.

Keep tolerance and installation allowances separate

An exact conversion does not mean that fabrication or site measurement has unlimited precision. Request the offered model's current dimensional information and ask the proposed fabricator to confirm what it can supply. The project designer and installer must determine the applicable installation allowances for the selected assembly. Record those decisions separately from the conversion column so that a gap, trimming allowance or other adjustment is not silently included twice. Do not round a piece upward to fit a familiar catalogue description or assume that a nominal sheet size guarantees a usable finished area. Where the required piece and the offered material do not align, request an explicit layout decision.

Approve the dimensional handoff before release

Send a controlled schedule containing piece identification, source dimensions, source units, controlling dimensions and orientation references. Name the person responsible for resolving discrepancies. Ask the receiving fabricator or supplier to acknowledge which values govern the proposed work, rather than relying on a general reply that the drawings were received. If a dimension changes, replace the affected schedule and identify the changed pieces; do not leave two valid-looking files in the same instruction package. At the first-piece review, compare the piece with the approved dimensional record using the agreed inspection method. Hold further release if units or acceptance criteria remain unclear.

Before you request a quotation

  • Every source dimension has an explicit unit and a clear purpose.
  • Conversions retain the original value and use one controlling unit.
  • Tolerances and installation allowances are approved separately.
  • Piece orientation, discrepancy owner and first-piece check are recorded.

Frequently asked questions

Does converting a nominal sheet size confirm the finished usable size?

No. Conversion changes the unit, not the meaning or accuracy of the original description. Request the current offered model information and the relevant fabrication details before approving the layout.

Should purchasing choose a rounding rule when the drawings disagree?

Not unilaterally. Ask the drawing owner and responsible fabrication or installation team to resolve the discrepancy and document the approved controlling dimension. A tidy spreadsheet is not a design approval.
